# Keyboard shortcuts

## YARA editor

| Shortcut | Action |
|---|---|
| Ctrl+T | New rule tab |
| Ctrl+S | Save rule |
| Ctrl+Shift+F | Format active rule |
| Ctrl+Shift+L | Check rule manually |
| Ctrl+Space | Request suggestions |
| Ctrl+W | Toggle word wrapping |
| Ctrl+G | Go to line |
| Ctrl+H | Open hex editor |
| Ctrl+, | Editor settings |
| Ctrl+Scroll | Zoom editor font |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Esc | Dismiss suggestions |
| Tab / Shift+Tab | Navigate snippet fields |

## Hex editor

| Shortcut | Action |
|---|---|
| Ctrl+O | Open file |
| Ctrl+F | Find bytes/text/regex |
| Ctrl+Shift+S | Save edited binary as… |
| Ctrl+Shift+E | Save selection as… |
| Ctrl+T | Toggle hex/text view |
| Ctrl+Scroll | Zoom hex/text font at the pointer |
| Ctrl++ / Ctrl+= | Increase hex/text font size |
| Ctrl+− | Decrease hex/text font size |
| Ctrl+0 | Reset hex/text font to its configured size |
| Ctrl+Z | Undo edit |
| Ctrl+Shift+Z | Redo edit |
| Insert | Toggle insert/overwrite |
| Ctrl+V | Paste |

Close the Find dialog or click its Cancel button to stop its active search.

## Offline Help

| Shortcut | Action |
|---|---|
| Ctrl+F | Find text in the current page |
| Enter / F3 / Ctrl+G | Next match (wraps) |
| Shift+Enter / Shift+F3 / Ctrl+Shift+G | Previous match (wraps) |
| Esc in the find field | Close the find bar |

The top search field filters the full offline collection; the find bar searches
only the page you are reading.
